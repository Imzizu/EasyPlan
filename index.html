How EasyPlan works

          
        

        

          
    
            
  1. Copy the /grillme template and send it to your coding LLM with the product idea.
    2. 
            
  2. When the model asks its questions, copy the entire reply — not just the list.
    3. 
            
  3. Paste it here and build the form. The compiler maps each item onto a ready-made field.
    4. 
            
  4. Answer everything. Preview the markdown if you want to inspect it.
    5. 
            
  5. Copy or download the response and paste it back so the LLM can write PLAN.md.
